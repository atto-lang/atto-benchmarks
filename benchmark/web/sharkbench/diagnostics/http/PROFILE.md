# Request-level JFR diagnostic

Use `bash profile.sh COMPILER UPSTREAM NEW_OUTPUT_DIR` on Linux with GraalVM JDK25, Cargo, Maven, Node, jcmd and jfr. Pins tested parser PR #1859 and unchanged native guest blob plus official data source. Runs a validated uninstrumented load before starting recording, then three validated loads with the same 32-client driver, exact upstream fetch counts, and single application CPU. Retains raw JFR, logs, environment, and deterministic top-30 sample attributions. Execution samples are statistical counts; allocation sample weights are estimates, not retained bytes or exact allocation totals. First Atto frame attribution is exclusive, not inclusive. This is not a proof of actor-arena reclamation and profiled throughput must not be used as an official score. No guest source or runtime changes.
